# AiroPost — бот погоды и качества воздуха

Telegram-бот на **aiogram 3**: каждый день в выбранное время присылает сводку погоды
и индекс качества воздуха (AQI, как в IQAir) для выбранного города или геолокации.

## Что умеет

- **Погода сейчас**: температура, «ощущается как», ветер (скорость, направление, порывы, сила по Бофорту),
  влажность и точка росы, давление (мм рт. ст. и гПа), облачность, видимость, УФ-индекс,
  восход и закат, длина светового дня, прогноз на ночь, утро, день и вечер
- **Почасовой прогноз** на 48 часов (4 страницы) и **прогноз на 7 дней**
- **Качество воздуха**: US AQI с цветовой шкалой, основной загрязнитель, европейский индекс,
  концентрации PM2.5, PM10, O₃, NO₂, SO₂, CO и пыли относительно суточной нормы ВОЗ,
  рекомендации (спорт, окна, маска, очиститель воздуха) и прогноз AQI каждые 3 часа
- **Местность**: поиск по названию («Ташкент», «Бухара, Узбекистан», «Toshkent») или геолокация
- **Ежедневная сводка** в выбранное время по местному времени этой местности; её можно включать и выключать

## Чистый чат

- Все экраны открываются **редактированием одного сообщения** бота, новые меню не добавляются.
- Сообщения пользователя (название города, время, геолокация, стикеры) бот удаляет сразу после обработки.
- Когда без нового сообщения не обойтись (`/start` или ежедневная сводка с уведомлением), бот отправляет его
  внизу чата, а **предыдущее удаляет**. В чате всегда остаётся одно сообщение бота.
- Кнопку «Отправить геолокацию» Telegram даёт сделать только обычной (не inline) клавиатурой, поэтому
  на время выбора местности под меню появляется подсказка с этой кнопкой. Она исчезает вместе с клавиатурой,
  как только местность выбрана.

## Источники данных

| Что | Откуда | Ключ |
|---|---|---|
| Погода, прогноз | [Open-Meteo](https://open-meteo.com) | не нужен |
| Качество воздуха | [Open-Meteo Air Quality](https://open-meteo.com/en/docs/air-quality-api) (модель CAMS) | не нужен |
| AQI со станций | [IQAir](https://www.iqair.com/air-pollution-data-api) | `IQAIR_API_KEY`, необязательно |
| Поиск городов | Open-Meteo Geocoding | не нужен |
| Адрес по геолокации | OpenStreetMap Nominatim | не нужен |

С ключом IQAir индекс AQI и основной загрязнитель берутся с ближайшей станции IQAir (цифры как в приложении),
концентрации и прогноз — из Open-Meteo. Ответы API кэшируются на 10–30 минут.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env
```

Впишите `BOT_TOKEN` в `.env` и запустите:

```bash
python -m bot
```

## Команды

- `/start` — погода сейчас (или приветствие, если местность ещё не выбрана)
- `/location` — сменить местность
- `/settings` — настройки: местность, время сводки, включение и выключение

Также в любой момент можно просто написать название города или отправить геолокацию.

## Структура

```
bot/
  __main__.py        запуск: бот, база, планировщик
  config.py          настройки из .env
  db.py              SQLite: пользователи, местность, время, id «живого» сообщения
  ui.py              чистый чат: редактирование, замена и удаление сообщений
  screens.py         сборка экранов (данные + текст + клавиатура)
  texts.py           тексты и форматирование
  keyboards.py       inline-клавиатуры и callback data
  scheduler.py       ежедневная рассылка
  timeutil.py        правила расписания
  states.py          FSM-состояния
  handlers/          команды, навигация, местность, время, очистка
  services/          клиенты погодных API
```

## Как работает расписание

- Время сводки — местное для выбранной местности (часовой пояс определяется автоматически).
- Планировщик проверяет пользователей каждые 20 секунд. Если бот был выключен в момент рассылки,
  сводка придёт после запуска, но не позже чем через час после назначенного времени.
- Если сменить время на уже прошедшее сегодня, первая сводка придёт завтра, а не сразу.
- Состояния FSM хранятся в памяти: после перезапуска незавершённый выбор местности просто сбрасывается.
  Настройки пользователей хранятся в SQLite и не теряются.
